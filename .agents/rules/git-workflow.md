# Git Workflow Rules

When working in this repository, follow these strict version control rules at all times:

1. **Do not auto-commit or auto-push**: Do not run `git add`, `git commit`, or `git push` unless the user EXPLICITLY instructs you to do so.
2. **Work in separate branches**: Whenever making new changes, always create and checkout a new, separate branch first. Do not work directly on the `main` or `master` branch.
3. **Do not auto-merge**: Even if a feature is complete and working properly, do not merge the branch into `main` unless the user explicitly tells you to do so.
